Built for the work,
not the ceremony.

e keeps the agent loop direct: local tools, inspectable work, and no framework between you and the task.

Harness

A harness, not a wrapper.

Models call local tools and consume their results until the task is done. Runs remain inspectable, bounded, and cancellable.

Providers

Your models, your keys.

Connect OpenAI, Ollama, LM Studio, vLLM, OpenRouter, or any compatible endpoint. Switch providers per conversation.

Runtime

Native by design.

Tauri uses the operating system webview instead of bundling a browser. The result is a focused app with a deliberately small renderer.

Workspaces

Work stays isolated.

Chats carry their own workspace, model, history, and budget. Git projects can use an app-managed worktree for every task.

Open where it matters.

Keep the core lean. Add capability at the edge through explicit, composable surfaces.

Install e.
Keep it simple.

Windows 10 or 11 and PowerShell 7 are all you need. The installer runs per-user, never elevates, and verifies the release before it starts.

powershell 
$ irm https://eharness.dev/install.ps1 -OutFile $env:TEMP\e.ps1; pwsh -NoProfile -File $env:TEMP\e.ps1

signed manifest + SHA-256 verified
